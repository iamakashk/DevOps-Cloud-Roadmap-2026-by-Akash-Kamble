# AWS Career Roadmap (Beginner → Advanced)

---

## 🟢 ENTRY / BEGINNER ROLES

### 1. AWS Cloud Practitioner / Fresher
**Who:** Non-IT, freshers, career switchers  
**Goal:** Understand AWS ecosystem, pricing, and core services  

**AWS Services to Learn**
- IAM (users, roles, policies – basics)
- EC2 (what it is, why it’s used)
- S3 (storage concepts)
- VPC (high-level understanding)
- RDS (managed databases – intro)
- CloudWatch (monitoring – overview)
- Billing & Cost Explorer
- AWS Global Infrastructure

---

### 2. AWS Cloud Support Engineer (L1/L2)
**Who:** Support, operations, ticket-based roles  
**Goal:** Troubleshoot AWS infra issues  

**AWS Services to Learn**
- IAM (policies, permission troubleshooting)
- EC2 (start/stop, security groups, AMIs)
- EBS (volumes, snapshots)
- S3 (bucket policies, access issues)
- VPC
- Subnets
- Route Tables
- Security Groups vs NACL
- CloudWatch (logs, alarms)
- CloudTrail (who did what)
- AWS Console + CLI (basic)

---

## 🟡 INTERMEDIATE CORE ROLES

### 3. AWS Cloud Engineer / Infrastructure Engineer
**Who:** Infra builders & maintainers  
**Goal:** Design and manage cloud infrastructure  

**AWS Services to Learn**
- EC2 (deep dive)
- Auto Scaling Groups
- Launch Templates
- Elastic Load Balancer (ALB, NLB)
- VPC (detailed)
  - Public & Private Subnets
  - IGW, NAT Gateway
  - Route Tables
  - VPC Peering
- IAM (roles, least privilege)
- RDS (Multi-AZ, backups)
- S3 (lifecycle, versioning)
- CloudWatch (metrics, alarms)
- CloudTrail
- AWS Backup
- Route 53 (DNS basics)

---

### 4. AWS Developer (Backend / Application Developer)
**Who:** Application developers  
**Goal:** Build scalable cloud-native apps  

**AWS Services to Learn**
- Lambda
- API Gateway
- DynamoDB
- RDS (app-side usage)
- S3 (events, static hosting)
- IAM (service roles)
- CloudWatch Logs
- SNS
- SQS
- Step Functions
- AWS SAM / Basic CloudFormation

> ❌ No need for deep VPC routing or NAT design.

---

### 5. AWS DevOps Engineer (Intermediate)
**Who:** Automation, CI/CD, infra + code  
**Goal:** Automate deployments & scaling  

**AWS Services to Learn**
- EC2 + Auto Scaling
- Elastic Load Balancer
- IAM (advanced role usage)
- VPC (solid understanding)
- CloudFormation (**MANDATORY**)
- CodeCommit
- CodeBuild
- CodeDeploy
- CodePipeline
- S3 (artifacts)
- CloudWatch + CloudTrail
- ECR
- ECS (intro level)

> 👉 **No CloudFormation = Not DevOps**

---

## 🟠 SPECIALIZED INTERMEDIATE ROLES

### 6. AWS Data Engineer / Analytics Engineer
**Who:** Data pipelines & analytics  
**Goal:** Process & analyze data on AWS  

**AWS Services to Learn**
- S3 (data lake)
- Glue
- Athena
- Redshift
- IAM (data access roles)
- Lake Formation
- Kinesis (Streams & Firehose)
- CloudWatch (data monitoring)

---

### 7. AWS Security Engineer
**Who:** Cloud security specialists  
**Goal:** Secure AWS environments  

**AWS Services to Learn**
- IAM (advanced)
- Organizations & SCPs
- KMS
- Secrets Manager
- GuardDuty
- Security Hub
- Inspector
- Shield
- WAF
- CloudTrail
- Config

---

### 8. AWS Network Engineer
**Who:** Networking specialists  
**Goal:** Design secure, scalable AWS networks  

**AWS Services to Learn**
- VPC (expert level)
- Route Tables
- IGW, NAT Gateway
- Transit Gateway
- VPC Peering
- Direct Connect
- VPN
- Route 53

## 🔵 ADVANCED / PROFESSIONAL ROLES

### 9. AWS Solutions Architect
**Who:** System designers  
**Goal:** Architect scalable, cost-effective systems  

**AWS Services to Learn**
- VPC (advanced design)
- EC2, ASG, ELB
- RDS, DynamoDB
- S3 (architecture patterns)
- CloudFront
- Route 53
- IAM (cross-account)
- CloudFormation
- Cost Explorer
- Well-Architected Framework

---

### 10. AWS Platform Engineer
**Who:** Internal cloud platform builders  
**Goal:** Build reusable cloud platforms  

**AWS Services to Learn**
- IAM + Organizations
- VPC (multi-account)
- CloudFormation / CDK
- Control Tower
- SSM
- Service Catalog
- CloudWatch
- EKS (platform level)
- Security Hub

---

### 11. AWS DevSecOps Engineer
**Who:** Security + DevOps  
**Goal:** Secure CI/CD & infrastructure  

**AWS Services to Learn**
- IAM
- KMS
- Secrets Manager
- CodePipeline + CodeBuild
- Inspector
- GuardDuty
- Security Hub
- CloudTrail
- SSM Parameter Store

---

### 12. AWS Machine Learning Engineer
**Who:** AI / ML professionals  
**Goal:** Build ML systems on AWS  

**AWS Services to Learn**
- SageMaker
- S3 (datasets)
- IAM
- Lambda
- API Gateway
- ECR
- CloudWatch
- Step Functions

📌 Disclaimer

This roadmap is intended as a general guidance reference, not a strict or exhaustive learning path.
AWS services, best practices, role expectations, and industry requirements evolve frequently.
The tools and services listed here may change, expand, or become deprecated over time.
Always refer to official AWS documentation and real-world project requirements when planning your learning or career path.
